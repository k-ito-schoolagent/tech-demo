OPEN SOURCE

みんなでデモを増やしていきましょう。

このラボはオープンソースです。授業で見せたい仕組み、自分が好きな機械や回路を、だれでも1ページのデモとして追加できます。GitHub がはじめての方の issue やプルリクエストの練習にも使ってください。

  1. 話してみる「こんなデモがほしい」「ここの説明がまちがっている」を issue に書く
  2. 直す・足す説明文の改善、モデルの前提の追記、テストの追加をプルリクエストで送る
  3. デモをつくる見本の「単振り子」をコピーして、自分のデモを1ページつくる
参加のしかたを読む issue を書く GitHub のリポジトリ
